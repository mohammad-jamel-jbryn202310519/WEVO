# WEVO 🚀
منصة وتطبيق ذكي متعدد المنصات (Web, Android, iOS) مبني باستخدام **Next.js 16**, **Node.js**, **Supabase**, و **Capacitor**.

---

## 🌟 ميزات المشروع (Key Highlights)

- **Next.js 16 & React 19**: واجهة سريعة بتصميم عصري داعم للعربية والإنجليزية والوضع الليلي (Dark Mode).
- **Supabase SSR**: ربط آمن لقاعدة البيانات وجلسات المستخدمين عبر `@supabase/ssr` ومفتاح الـ API.
- **تطبيق هاتف أصلي (Mobile Ready)**: معد وجاهز للتحويل إلى تطبيقات Android (Google Play) و iOS (App Store) عبر **Capacitor**.
- **جاهز للنشر على Hostinger**: يحتوي على `ecosystem.config.js` لتشغيل المشروع تلقائياً على خوادم Node.js و PM2.

## 🗄️ تهيئة قاعدة بيانات Supabase (SQL Setup)

لتفعيل ميزة حفظ البيانات السحابية (Todos / Users)، نفذ الاستعلام التالي في **Supabase SQL Editor**:

```sql
create table public.todos (
  id bigint generated by default as identity primary key,
  name text not null,
  is_complete boolean default false,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table public.todos enable row level security;

create policy "Allow public access" 
on public.todos 
for all 
using (true) 
with check (true);
```

## 📱 تصدير المشروع إلى تطبيق Android & iOS

المشروع مضبوط مع **Capacitor**:

### لتطبيق Android:
```bash
npm run build
npx cap add android
npx cap open android
```
سيفتح **Android Studio** لإنشاء حزمة APK أو AAB مباشرة.

### لتطبيق iOS:
```bash
npm run build
npx cap add ios
npx cap open ios
```
سيفتح **Xcode** (على نظام macOS) لتشغيل التطبيق على iPhone.

## 🌐 النشر على سيرفر هوستنجر (Hostinger Server Deployment)

1. **رفع التعديلات إلى GitHub**:
   ```bash
   git add .
   git commit -m "Deploy WEVO update"
   git push -u origin main
   ```

2. **سحب المشروع في سيرفر Hostinger (عبر SSH)**:
   ```bash
   git clone https://github.com/mohammad-jamel-jbryn202310519/WEVO.git
   cd WEVO
   npm install
   cp .env.example .env.local  # قم بوضع مفاتيحك
   npm run build
   ```

3. **التشغيل المستمر عبر PM2**:
   ```bash
   pm2 start ecosystem.config.js
   pm2 save
   pm2 startup
   ```
